## 🔬 Core Research Focus
- **Speech Signal Processing**: Bone-Conducted (BC) speech enhancement, spectral estimation, and acoustic reconstruction.
- **Signal Modeling**: Modified Linear Prediction (MLP) and Regularized Modified Covariance (RMC) methods for ill-conditioned speech.
- **VoIP Telecommunications**: Packet Loss Concealment (PLC) utilizing bone-conducted sensory data.
- **Natural Language Processing (NLP)**: Universal Networking Language (UNL), Bengali NLP, and ambiguity-resolving machine translation.
- **Applied AI & Healthcare Informatics**: Machine learning and deep vision models for diagnostic prediction (Diabetic Retinopathy, Chronic Kidney Disease, Parkinson's, Cancer classification).
